# 众筹系统设计文档 (设计版)

## 1. 引言

本文档定义了众筹系统的视觉设计规范与交互原型。系统旨在通过“信任与权威”的设计语言，向赞助者传达透明度与专业感。

## 2. 核心设计方向：信任与专业 (Trust & Authority)

- **视觉基调**：沉稳、专业、透明、安全。
- **色彩策略**：以专业蓝为核心，搭配深青色强调权威感，辅以清爽的背景色。
- **排版系统**：使用高可读性的无衬线字体，强化数据展示。

## 3. UI 规范

### 3.1 色彩系统 (蓝色系)

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| **主色 (Primary)** | `#1e40af` (Blue 800) | 导航栏、主要标题、品牌核心 |
| **强调色 (Accent)** | `#2563eb` (Blue 600) | 核心按钮 (CTA)、支付成功状态 |
| **辅助色 (Secondary)** | `#3b82f6` (Blue 500) | 链接、次要操作、交互反馈 |
| **背景色 (Background)** | `#f8fafc` (Slate 50) | 页面整体背景 |
| **表面色 (Surface)** | `#ffffff` (White) | 卡片、列表项、表单容器 |
| **文字 (Foreground)** | `#0f172a` (Slate 900) | 正文、重要数值 |
| **静默文字 (Muted)** | `#64748b` (Slate 500) | 备注、次要说明、时间戳 |

### 3.2 字体排版

- **字体族**：`"Inter"`, `"IBM Plex Sans"`, `"PingFang SC"`, system-ui.
- **标题**：加粗 (Font Weight 700)，紧凑的字间距。
- **数值展示**：金额展示使用等宽数字 (Tabular Figures)，强化财务属性。

### 3.3 交互动效

- **平滑过渡**：所有悬停状态 (Hover) 响应时间为 `150-200ms`。
- **加载态**：使用骨架屏 (Skeleton Screen) 替代传统加载圈。
- **数值滚动**：资金池余额展示建议使用数字滚动动画。

## 4. 界面原型设计 (展示)

### 4.1 首页 (资金池中心)
- **头部**：沉稳的深蓝导航，包含“资金池”、“众筹记录”、“支出明细”。
- **英雄区 (Hero)**：大字号展示 `¥ 123,456.78` 余额，背景采用极简的蓝色几何渐变。
- **数据面板**：三栏式展示“累计赞助”、“累计支出”、“赞助人数”，数值加粗。
- **快捷入口**：显眼的蓝色“立即赞助”按钮。

### 4.2 众筹记录列表
- **列表设计**：干净的白色卡片，左右分布。左侧展示昵称与留言，右侧展示金额与时间。
- **状态标识**：若有退款，金额下方显示淡蓝色“部分退款”标签。

### 4.3 赞助表单
- **多步感**：简洁的输入框，预设 `¥50`, `¥100`, `¥500` 快捷选项。
- **信任元素**：表单下方附带“资金透明公示”与“隐私安全保护”图标。

### 4.4 管理后台
- **侧边栏**：专业深色导航。
- **管理表格**：高对比度的文本，支持快速退款操作按钮（红色边框）。

## 5. 组件开发指南 (基于 Tailwind v4)

- 使用 `ring` 强化聚焦状态。
- 使用 `backdrop-blur` 提升悬停层质感。
- 遵循 `mobile-first` 原则。

## 6. 数据架构 (核心实体)

### 6.1 `pledges` (赞助记录)
- 包含基础金额、订单信息。
- 新增 `tms_status` (Enum: PENDING, APPROVED, REJECTED) 记录文本审核状态。

### 6.2 `system_settings` (系统配置)
- `id`: UUID (PK)
- `key`: String (唯一键，如 `site_title`, `favicon_url`, `hero_title`, `tms_enabled`)
- `value`: Text (配置值)
- `updated_at`: Timestamp

## 7. API 设计概览与第三方集成

### 7.1 系统与 TMS 集成
- 用户提交赞助表单后，系统将在后台异步或同步调用 TMS (Text Moderation System) API 校验 `nickname` 和 `message`。
- 若 TMS 返回违规，系统应拦截创建或将其状态置为不可见，防止风险内容公开。

### 7.2 管理端配置 API
- `GET /api/admin/settings`：获取系统全局配置。
- `PUT /api/admin/settings/:key`：更新指定配置项。
